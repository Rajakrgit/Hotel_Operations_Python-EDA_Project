# Hotel_Operations_Python-EDA_Project
This project was Hotel Harmony: Data Insights for Optimized Operations. The main objective was to analyze hotel booking data to understand booking patterns, investigate cancellations, and identify opportunities to improve hotel operations and revenue management.

I worked with a hotel booking dataset containing information about City Hotels and Resort Hotels, booking lead times, arrival dates, customer characteristics, booking channels, room types, special requests, and Average Daily Rate.

I used Python as the primary programming language, Pandas and NumPy for data manipulation, Matplotlib and Seaborn for visualization, and Scikit-learn for regression modeling.

One of the main challenges was handling duplicate records and missing values before performing the analysis. I also needed to interpret booking patterns carefully because correlation does not necessarily prove causation.

One important finding was that City Hotels had a cancellation rate of approximately 30.04%, compared with 23.48% for Resort Hotels. I also found that August had the highest number of booking records in the cleaned dataset, while the correlation between booking lead time and cancellation was approximately 0.185.

I also developed a logistic regression model to investigate cancellation risk. It achieved a ROC-AUC of 0.762 on the test set, although its precision for canceled bookings showed that there was room for improvement.

Based on these findings, I would recommend investigating City Hotel cancellations, reviewing seasonal staffing and pricing strategies, evaluating booking channels, and improving the cancellation prediction model.

Overall, this project improved my Python, exploratory data analysis, data visualization, and machine-learning skills. It also helped me understand how data-driven insights can support better operational decisions.
